# 오늘공부

혼자 공부하는 고등학생을 위한 웹 앱입니다.
남은 단원을 고르면 **날짜별 공부 계획표**를 만들어 주고, **난이도별 수학 문제**를 내서 채점·풀이·복습까지 한 화면에서 도와줍니다.

- 대상: 혼자 공부하는 고등학생 (1~3학년)
- 과목: 수학 (공통수학1, 공통수학2, 기하 — 24개 단원)

## 주요 기능

### 1. 하루 공부 분량 계획
- 남은 단원, 공부할 기간(1~30일), 하루 공부 시간(30~480분)을 입력합니다.
- 날짜별로 개념 / 기본 문제 / 응용 문제 / 정리 시간을 분 단위로 보여줍니다.
- 하루 시간 합계 초과 방지, 하루 새 단원 최대 2개, 5일 이상이면 마지막 날 복습일 같은 규칙을 코드로 다시 검사합니다.
- 기간 안에 다 들어가지 않으면 계획을 만들지 않고, 며칠 또는 몇 분으로 늘려야 하는지 알려줍니다.

### 2. 난이도별 문제 → 채점 → 풀이 → 복습
- 단원을 고르면 [쉬움]·[응용]·[심화] 난이도가 표시된 주관식 단답 문제를 냅니다.
- 학생이 답을 내기 전에는 정답과 풀이를 브라우저로 보내지 않습니다. (정답은 서버만 열 수 있는 잠금 토큰에 보관)
- 문제는 AI가 낸 뒤, 정답을 모르는 상태로 다시 풀게 해서 두 답이 같은 것만 사용합니다.
- 채점은 코드가 먼저 합니다. (`1/2`와 `0.5`, `√2`와 `루트2`처럼 모양이 달라도 같은 값이면 정답) 애매한 답만 AI에게 묻습니다.
- 문제마다 O/X, "4문제 중 3문제 정답", 단계별 풀이, 틀린 곳 한 줄을 보여줍니다.
- 틀린 문제마다 같은 유형의 복습 문제를 1개씩(최대 5개), 한 번만 냅니다. 복습에서 또 틀리면 짧은 개념 설명을 보여줍니다.
- 모두 맞히면 [응용]+[심화] 세트로 올리고, 심화를 2개 이상 틀리면 기본 세트로 돌아갑니다.

## 만들지 않은 것
로그인, 기록 저장(데이터베이스), 수학 외 과목, 사진·손글씨 인식, 그래프·도형 그림, 결제, 스마트폰 앱.
새로고침하면 계획과 문제는 사라집니다. 이름·학교·연락처는 받지도 저장하지도 않습니다.

## 기술
- Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4
- AI: OpenAI Chat Completions (기본 모델 `gpt-5.4-mini`, `OPENAI_MODEL`로 바꿀 수 있음)
- 배포: Vercel
- API 키는 서버 코드(`app/api/`, `lib/server/`)에서만 읽고 브라우저로 보내지 않습니다.

## 실행 방법

```bash
npm install
```

프로젝트 폴더에 `.env` 파일을 만들고 OpenAI 키를 넣습니다. (`.env`는 GitHub에 올라가지 않습니다)

```
OPENAI_API_KEY=여기에_본인_키
```

```bash
npm run dev     # 개발 서버 (http://localhost:3000)
npm run build   # 배포용 빌드
npm run lint    # 코드 검사
npm run check -- http://localhost:3000   # 성공 기준 자동 점검
```
